## 1. 产品摘要与关键决策

> **产品核心**
>
> TT16 不是“测你能不能赚钱”，而是测“你通常依靠什么形成观点、选择多长兑现周期、如何表达风险、怎样执行计划”，并提示在压力下最容易出现的行为偏差。

### 1.1 MVP 关键决策

| **决策项** | **MVP 选择**                                           | **原因**                                                |
|------------|--------------------------------------------------------|---------------------------------------------------------|
| 载体       | 移动端优先的响应式 H5                                  | 最低传播门槛，适配微信、社区与二维码入口。              |
| 测试长度   | 32 道基础题，必要时最多 2 道边界决胜题                 | 兼顾完成率与四维度稳定性；决胜题仅在 48%–52% 边界触发。 |
| 核心输出   | 4 字母类型 + 16 型人格名 + 4 维度百分比 + 6 个风险徽章 | 既满足分享，也提供可执行的行为洞察。                    |
| 账号体系   | 默认匿名，不强制登录                                   | 减少首测流失；登录与历史对比放入 P1。                   |
| 商业化     | MVP 不付费、不售卖荐股                                 | 先验证完成率、结果认同与分享传播。                      |
| 数据连接   | MVP 不导入券商流水                                     | 规避隐私和合规复杂度；P2 再做“自评 vs 真实行为”。       |
| 品牌关系   | 不宣称与 MBTI 官方、Myers-Briggs 或任何券商存在关联    | 降低商标、误导宣传和金融营销风险。                      |

### 1.2 一页式产品概览

| **32** | **4 × 2** | **5–7 分钟** | **16** |
| --- | --- | --- | --- |
| **基础题数**<br>24 核心 + 6 偏差 + 2 一致性 | **核心维度**<br>组合为 16 种类型 | **目标完成时长**<br>中位数，首发后校准 | **人格结果**<br>无高低优劣排序 |

| **模块** | **用户得到什么**                      | **产品得到什么**                |
|----------|---------------------------------------|---------------------------------|
| 人格测试 | 一个清晰、有记忆点的交易人格身份      | 低门槛获客与结构化偏好数据      |
| 结果报告 | 优势、盲点、压力模式和交易守则        | 结果认同、停留与二次访问        |
| 分享卡片 | 可截图、可讨论、可对比的社交内容      | 自然传播和裂变回流              |
| 风险徽章 | 对 FOMO、死扛、冲动等偏差的提醒       | 从娱乐测试升级为行为改进工具    |
| 后续扩展 | 历史对比、交易流水验证、团队/社区画像 | 长期留存、付费或 B 端合作可能性 |

## 2. 背景、定位与产品原则

### 2.1 用户问题

- 很多投资者能描述“我看基本面”或“我做短线”，但无法系统解释自己的决策、持有、仓位和执行方式。
- 传统风险测评通常只输出“保守 / 稳健 / 进取”，信息量不足，也缺少社交传播性。
- 娱乐型股民测试容易获得分享，却常停留在“股神 / 韭菜 / 梭哈”等标签，无法支持真实复盘。
- 用户自认为的风格与真实交易行为可能不一致；TT16 先建立自评基线，未来再通过交易数据验证。

### 2.2 产品定位

> **定位语**
>
> 面向股票投资者的交易行为人格测试：前端好玩、易懂、可分享，后端中立、可解释、可复盘。

| **维度** | **TT16 的选择**                                              |
|----------|--------------------------------------------------------------|
| 品类     | 人格测试 × 行为金融 × 投资者教育                             |
| 目标用户 | 有股票交易经历或正在学习股票投资的中文用户                   |
| 核心价值 | 帮助用户识别稳定倾向、压力下偏差，以及适合自己的执行约束     |
| 差异化   | 不是只测风险承受能力；不是段子标签；未来可与真实交易行为对照 |
| 品牌语气 | 聪明但不说教；有梗但不羞辱；专业但不伪装成诊断或荐股         |

### 2.3 产品原则

| **原则**   | **产品要求**                                                       |
|------------|--------------------------------------------------------------------|
| 中立不排名 | 任何类型都有优势、适用环境与失效方式，不设置“最强人格”。           |
| 行为优先   | 尽量询问过去 12 个月真实行为，而不是用户理想中的自我描述。         |
| 可解释     | 每个字母、分数、徽章都能回溯到问题和规则，结果不可由黑箱随意生成。 |
| 低摩擦     | 不强制注册；断网可恢复；题目一屏一题；结果先展示再引导分享。       |
| 不越界     | 不预测收益、不推荐股票、不鼓励杠杆、不把人格当成投资适当性结论。   |
| 可迭代     | 题库、权重、结果文案和插画均版本化，支持 A/B 与心理测量验证。      |

### 2.4 非目标（MVP 不做）

- 不判断用户是否“会赚钱”，不输出预测收益率、胜率或可买标的。
- 不承担证券投资适当性评估、风险等级认证或投资顾问职责。
- 不接入实时行情、模拟盘、交易下单或券商账户。
- 不做公开排行榜，不通过“韭菜”等贬损词刺激分享。
- 不追求临床心理学或人格诊断效力；MVP 定位为行为风格自评工具。

## 3. 用户与核心场景

### 3.1 目标用户分层

| **用户**      | **典型特征**                            | **核心动机**                             | **产品机会**                                |
|---------------|-----------------------------------------|------------------------------------------|---------------------------------------------|
| 新手探索者    | 入市 0–2 年；知识碎片化；容易被行情影响 | 想知道自己适合长期还是短线，避免明显错误 | 低门槛解释四维度，给出简单交易守则          |
| 社区表达者    | 活跃于投资社区、群聊或内容平台          | 想获得有趣身份标签，与朋友比较讨论       | 人格卡、阵营感、分享文案与结果链接          |
| 自我改进者    | 有交易记录，常复盘但缺少结构化框架      | 想找到重复犯错的行为模式                 | 风险徽章、压力模式、可执行清单              |
| 内容/投教运营 | 券商、财经媒体、投资社群运营者          | 需要互动活动、用户分层和投教内容入口     | 可配置活动、匿名聚合数据与 B 端报告（后续） |

### 3.2 Jobs to Be Done

- 当我刚开始投资或经常改变方法时，我想用一个清晰框架认识自己的稳定偏好，从而减少盲目模仿别人。
- 当我经历大涨大跌后，我想知道自己在压力下为何会追高、死扛或复仇交易，从而建立约束。
- 当我和朋友讨论投资风格时，我想用一张有辨识度的结果卡表达自己，而不是长篇解释。
- 当我重新测试时，我想看人格是稳定、成熟了，还是只是最近行情改变了我的回答。

### 3.3 关键使用场景

| **场景**       | **触发**                     | **完成标准**                     |
|----------------|------------------------------|----------------------------------|
| 自然分享进入   | 看到朋友的 TT16 结果卡或链接 | 理解测试价值并开始答题           |
| 首次测试       | 对自己的交易风格好奇         | 完成有效问卷并查看完整结果       |
| 结果传播       | 结果有认同感或反差感         | 生成卡片并分享 / 保存            |
| 结果复盘       | 近期发生亏损、追高或交易失控 | 找到对应风险徽章和一条可执行守则 |
| 再次测试（P1） | 三个月后或经历市场风格变化   | 比较维度变化和稳定项             |

## 4. 目标、范围与成功指标

### 4.1 产品目标

| **目标**   | **定义**                       | **衡量方式**                               |
|------------|--------------------------------|--------------------------------------------|
| G1：完成   | 用户愿意开始并完成测试         | 开始率、有效完成率、中位完成时长           |
| G2：认同   | 结果让用户感到“像我，而且有用” | 结果认同反馈、报告展开率、收藏/截图意向    |
| G3：传播   | 结果具备自然分享价值           | 分享点击率、分享成功率、分享回流完成数     |
| G4：可信   | 评分稳定、可解释、无明显误导   | 一致性、重测稳定性、投诉率、低置信结果占比 |
| G5：可迭代 | 题目与内容可版本化优化         | 配置发布时间、版本追踪、实验归因完整度     |

### 4.2 北极星与首发假设指标

> **北极星指标**
>
> 有效完成并查看结果的测评数（Valid Result Views）：完成必答项、数据质量为中或高、且结果页停留 ≥ 10 秒。

| **指标**         | **首发假设目标** | **口径 / 备注**                           |
|------------------|------------------|-------------------------------------------|
| 落地页开始率     | ≥ 35%            | 点击“开始测试” / 落地页 UV                |
| 有效完成率       | ≥ 65%            | 有效提交 / 开始测评会话                   |
| 中位完成时长     | ≤ 7 分钟         | 从首题展示至提交；不含后台挂起 \> 10 分钟 |
| 结果页深度阅读率 | ≥ 50%            | 至少展开 2 个深度模块 / 结果页 UV         |
| 分享点击率       | ≥ 15%            | 点击生成或分享卡片 / 结果页 UV            |
| 分享回流完成率   | ≥ 20%            | 分享渠道新会话完成 / 分享回流新会话       |
| 技术错误率       | \< 0.5%          | 导致无法继续或无法出结果的会话占比        |

说明：以上为没有历史数据时的产品假设目标。首批 1,000 个有效样本后，应按渠道、设备与用户经验分层重新校准。

## 5. TT16 人格模型

### 5.1 四个核心维度

| **问题** | **左端** | **右端** | **测量定义** |
| --- | --- | --- | --- |
| 你主要看什么？ | R · Research<br>研究驱动 | S · Signal<br>信号驱动 | 形成观点时更依赖企业、财务和估值，还是价格、资金、趋势和市场反馈。 |
| 你愿意等多久？ | H · Hold<br>持有型 | T · Trade<br>交易型 | 更偏向长期等待价值兑现，还是在较短周期持续捕捉机会。 |
| 你通常下多大？ | D · Defensive<br>防守型 | A · Aggressive<br>进攻型 | 如何使用集中度、波动容忍与风险预算表达确信度。 |
| 你怎么执行？ | P · Planned<br>计划型 | F · Flexible<br>灵活型 | 更依赖预设规则与清单，还是根据新信息和盘面临场调整。 |

> **命名规则**
>
> 类型代码按照“信息来源—兑现周期—风险表达—执行方式”的顺序排列。例如 RHAP = 研究驱动、持有型、进攻型、计划型。

### 5.2 六个风险徽章

| **徽章**    | **要识别的问题**                               | **结果表达**                             |
|-------------|------------------------------------------------|------------------------------------------|
| 从众 / FOMO | 是否容易因暴涨、热搜、群聊和他人收益而改变计划 | 低 / 中 / 高敏感；提供“延迟决策”守则     |
| 损失厌恶    | 是否倾向过早卖出盈利仓、长期等待亏损仓回本     | 低 / 中 / 高；提示论点失效与沉没成本     |
| 信心校准    | 连续盈利后，仓位增长是否快于证据质量           | 稳健 / 偏高 / 过热；提示固定风险预算     |
| 交易冲动    | 亏损后是否急于追回、频繁反向或加速交易         | 稳定 / 波动 / 高风险；提示冷静期         |
| 回撤镇定    | 组合大幅下跌时能否先复核再行动                 | 冷静 / 紧张 / 易失控；提示预案与仓位匹配 |
| 复盘一致性  | 是否记录买卖理由，并区分结果好坏与过程好坏     | 系统 / 偶尔 / 薄弱；提示交易日志         |

徽章不参与 16 型代码生成，避免把“偏差”误当成稳定人格。MVP 中徽章属于探索性提示，不作心理诊断。

### 5.3 16 型人格总览

| **代码** | **人格名**   | **核心优势**                     | **主要盲点**                 |
|----------|--------------|----------------------------------|------------------------------|
| RHDP     | 复利园丁     | 深研、长持、分散、按规则复利     | 反应过慢；把稳定误当不必复核 |
| RHDF     | 价值守望者   | 重视价值回归，错杀时灵活加仓     | 价值陷阱；越跌越合理化       |
| RHAP     | 高确信舵手   | 深研少数公司，集中但有计划       | 确认偏误；单一持仓风险       |
| RHAF     | 信仰船长     | 长期信念强，能穿越大波动         | 爱上股票；失效后仍找借口     |
| RTDP     | 财报工程师   | 围绕财报、估值和催化做规则交易   | 过度建模；忽略成本与预期差   |
| RTDF     | 事件雷达     | 对公告与政策变化反应快、仓位灵活 | 信息焦虑；噪音过度交易       |
| RTAP     | 预期差狙击手 | 深研后集中捕捉市场错价           | 事件二元风险；下注过重       |
| RTAF     | 错杀猎手     | 极端定价中快速逆向出手           | 过早抄底；不断接下落的刀     |
| SHDP     | 趋势配置师   | 分散跟随中长期趋势并规则换仓     | 反转退出滞后；震荡磨损       |
| SHDF     | 轮动领航员   | 根据景气、风格和资金偏好轮动     | 换仓过快；风格漂移           |
| SHAP     | 赛道骑士     | 集中持有最强趋势和核心赛道       | 拥挤交易；高位接力           |
| SHAF     | 主题追光者   | 擅长捕捉主题、叙事和情绪扩散     | 故事大于数据；忽视兑现       |
| STDP     | 系统波段手   | 用技术信号和固定风险做波段       | 震荡反复止损；成本磨损       |
| STDF     | 盘面游侠     | 仓位轻、反馈快、临场适应强       | 过度交易；难以复盘复制       |
| STAP     | 突破狙击手   | 集中参与突破和动量，执行止损     | 假突破；连续止损后失控       |
| STAF     | 火箭驾驶员   | 速度快、集中、依赖盘面反应       | FOMO、复仇交易与杠杆风险     |

### 5.4 类型解释规则

- 使用“倾向”“更可能”“在压力下可能”等概率性语言，不使用“一定”“天生”“注定”。
- 类型只描述常见决策偏好，不等于能力、收益、道德、智力或风险承受能力。
- 结果必须同时展示百分比；51% R 与 95% R 的解释强度不同。
- 任一维度落在 48%–52% 时标注“边界型”，并允许用户查看两端差异。
- 结果页不显示类型排名、收益排名或“最适合购买的股票”。

## 6. 信息架构与用户流程

### 6.1 MVP 信息架构

| **一级页面** | **二级模块**                                                         |
|--------------|----------------------------------------------------------------------|
| 落地页       | 品牌主视觉、价值说明、预计时长、免责声明摘要、开始按钮               |

- 选择后 250–400 ms 自动进入下一题；用户可返回修改，修改后重新计算。
- 每 8 题显示轻量进度反馈，不使用“你已经更像某类型”等诱导文案。
- 连续 5 题答题用时 \< 800 ms 时，提交前提示“部分题目回答较快，可回看或直接提交”，不强制拦截。

### 7.7 反馈与纠错

- 结果认同：像我 / 一般 / 不像我。

## 8. 题库与评分引擎

### 8.1 题库结构

| **题型**   | **数量** | **作用**                                             |
|------------|----------|------------------------------------------------------|
| 核心维度题 | 24       | 每个维度 6 题，决定 R/S、H/T、D/A、P/F。             |
| 行为偏差题 | 6        | 估计六个风险徽章；部分核心题可交叉提供证据。         |
| 一致性题   | 2        | 与前题反向或平行表达，用于数据质量，不直接决定类型。 |
| 边界决胜题 | 0–2      | 仅在 48%–52% 边界触发，不计入基础题数。              |

### 8.2 单题计分

五档选择统一映射为 -2、-1、0、+1、+2。题目配置中定义 A 端与 B 端分别对应哪个字母，反向题通过 direction = -1 处理。

```text
answer_value ∈ {-2, -1, 0, +1, +2}
item_contribution = answer_value × direction × item_weight
“未经历过 / 不适用” = null，不计分，但降低 coverage
核心题默认 item_weight = 1.0；决胜题默认 item_weight = 1.25
```

### 8.3 维度标准化与类型生成

```text
raw_d = Σ(item_contribution) / Σ(2 × item_weight) # 范围 [-1, +1]
right_percent = round((raw_d + 1) × 50) # 范围 [0, 100]
left_percent = 100 - right_percent
letter = left_letter if left_percent ≥ right_percent else right_letter
type_code = concat(letter_RS, letter_HT, letter_DA, letter_PF)
```

显示规则：百分比按整数展示；计算保留至少 4 位小数。若恰好 50/50，使用该维度的高区分度锚点题作为确定性决胜；仍相同则沿用固定左端字母并标注“边界型”，以保证结果可复现。

### 8.4 边界、可信度与稳定度

| **指标**   | **计算建议**                           | **对用户表达**                                 |
|------------|----------------------------------------|------------------------------------------------|
| 维度边界   | 任一端 48%–52%                         | “这一维度较平衡，环境变化可能让你呈现另一侧。” |
| 覆盖度     | 有效答案数 / 可计分题数；每维至少 4 题 | 低覆盖时提示补答或输出低可信结果。             |
| 一致性     | 两组平行/反向题差异 + 同类题逻辑冲突   | 高 / 中 / 低；不公开复杂公式。                 |
| 响应质量   | 极短用时、全选同一档、频繁不适用       | 仅作为质量信号，不因“答得快”直接判无效。       |
| 类型稳定度 | 四个维度离 50% 的最小距离              | 稳定 / 有一项边界 / 多项边界。                 |

### 8.5 风险徽章评分

每个徽章由 1 道专门题 + 2–4 道交叉题组成，避免单题定性。每题配置 risk_weights，归一化到 0–100。阈值首版暂定 0–39、40–69、70–100 三档，需在预测试后校准。

| **徽章**    | **专门题** | **交叉证据示例**                          |
|-------------|------------|-------------------------------------------|
| 从众 / FOMO | Q25        | S、T、A、F 相关题中对追涨与即时反应的选择 |
| 损失厌恶    | Q26        | 卖出条件、论点失效、等待回本倾向          |
| 信心校准    | Q27        | 集中度、连续盈利后加仓、杠杆倾向          |
| 交易冲动    | Q28        | 止损后重入、临场反向、交易频率            |
| 回撤镇定    | Q29        | 回撤处理、仓位预算、复核流程              |
| 复盘一致性  | Q30        | 日志、检查清单、提前写退出条件            |

### 8.6 题目质量要求

- A/B 两端都必须合理，不出现“理性研究”对“盲目跟风”这种价值倾斜。
- 避免依赖用户没经历过的期权、期货、做空等情境；必要时提供“不适用”。
- 避免直接问“你是否冲动 / 自信 / 有纪律”，优先使用最近行为和具体场景。
- 同一维度至少包含正向、反向、不同市场状态和不同决策阶段的题目。
- 文案阅读难度面向普通投资者；单题正文建议 ≤ 90 个汉字。
- 不使用收益结果来暗示某答案正确，例如“这样更容易赚钱”。

### 8.7 验证计划

| **阶段**     | **样本 / 方法**                               | **通过标准（建议）**                                   |
|--------------|-----------------------------------------------|--------------------------------------------------------|
| 认知访谈     | 12–20 名不同经验用户逐题思考 aloud            | 能正确理解 A/B；无明显社会期许答案；不适用率可解释。   |
| 小规模预测试 | ≥ 200 个有效样本                              | 各选项有分布；单题缺失 \< 10%；无严重天花板/地板效应。 |
| 量表分析     | 按维度检查内部一致性、题目-总分相关与因子结构 | 删除或重写低区分度、强交叉载荷题；阈值由数据决定。     |
| 重测稳定     | 2–4 周后邀请复测                              | 类型与连续分数在合理范围稳定；边界用户允许变化。       |
| 结果效度     | 用户自评认同 + 可选交易行为指标               | 结果不只“像”，还能解释部分真实持有期、换手与集中度。   |

## 9. 结果内容系统

### 9.1 每个人格的内容模板

| **字段** | **字数 / 数量**     | **要求**                               |
|----------|---------------------|----------------------------------------|
| 人格名   | 4–6 字              | 有画面感，不羞辱，不承诺收益。         |
| 一句标语 | 16–28 字            | 准确说明主要优势与方法。               |
| 核心画像 | 120–180 字          | 覆盖四维度，不复述字母定义。           |
| 优势     | 3 条，每条 25–50 字 | 描述可观察行为与适用条件。             |
| 盲点     | 3 条，每条 25–50 字 | 与优势镜像，避免道德评判。             |
| 顺手环境 | 2–3 条              | 说明何种市场结构更利于发挥。           |
| 失效环境 | 2–3 条              | 说明何时应降低确信或仓位。             |
| 压力模式 | 80–140 字           | 连续亏损、暴涨或回撤时可能如何偏移。   |
| 交易守则 | 5 条                | 具体、可检查、可复制。                 |
| 分享文案 | 1 主 2 备           | 不过度夸张；含邀请朋友测试的自然钩子。 |

### 9.2 示例结果：RHAP 高确信舵手

> **我的 TT16：RHAP · 高确信舵手**
>
> 你愿意花时间理解少数真正看懂的公司，并用集中仓位表达判断；你的关键不是“研究更多”，而是提前定义什么证据会让自己承认判断失效。

| **模块**   | **示例内容**                                                                     |
|------------|----------------------------------------------------------------------------------|
| 四维度     | R 82% · H 71% · A 76% · P 68%                                                    |
| 优势       | 能把复杂信息形成独立判断；愿意等待长期逻辑；仓位与确信度匹配；执行前有计划。     |
| 盲点       | 容易只寻找支持原观点的信息；集中仓位放大单点错误；计划可能写得清楚却执行得宽松。 |
| 压力模式   | 连续下跌时，可能从“按证据持有”滑向“用信仰解释一切”，不断放宽论点失效条件。       |
| 高相关徽章 | 信心校准、损失厌恶、复盘一致性。                                                 |
| 首条守则   | 建仓前写下 3 个可验证的看多证据和 2 个必须减仓的失效证据。                       |

### 9.3 文案禁区

- 禁止：“你天生适合炒短线”“该人格平均年化 30%”“你应该买科技股”。
- 禁止：“韭菜”“赌徒”等贬损性官方人格名；用户生成内容另行治理。
- 禁止把进攻型等同“高风险承受能力”，或把防守型等同“低收益”。
- 禁止暗示测试已通过官方 MBTI、心理学会、证券监管或券商认证。
- 推荐：“你更倾向……”“在……环境下更容易发挥”“当……发生时，建议先……”。

| retest_click        | 点击重测         | previous_type, version           |

### 10.3 实验优先级

| **实验**       | **变量**                         | **主要指标**     | **护栏指标**       |
|----------------|----------------------------------|------------------|--------------------|
| 落地页价值表达 | “认识优势盲点” vs “测出人格身份” | 开始率           | 完成率、投诉率     |
| 题目自动前进   | 自动前进 vs 手动下一题           | 完成时长、完成率 | 误触返回率         |
| 结果首屏       | 人格身份优先 vs 四维数据优先     | 停留、展开率     | 结果认同           |
| 分享卡文案     | 身份型、反差型、洞察型           | 分享点击、回流   | 负面反馈           |
| 结果深度       | 短报告 vs 分层展开               | 阅读深度         | 首屏跳出、加载性能 |

### 10.4 数据最小化原则

- 会话可用随机标识，不采集姓名、身份证、券商账户或精确资产规模。
- IP 仅用于安全与聚合统计时应缩短保留期并脱敏；产品分析优先使用匿名 session。
- 原始答案与结果分开授权；公开结果链接只包含结果，不包含逐题答案。
- 用户应能删除本地进度；绑定账号后应提供删除历史记录入口。
- P2 交易流水导入需单独 PRD、单独同意和更严格安全评审。

### 11.1 性能与兼容性

| **项目** | **要求**                                                                         |

### 11.2 安全要求

- 全站 HTTPS；分享 token 使用高熵随机值，不可由自增 ID 枚举。
- 服务端校验题库版本、答案范围和提交幂等，防止篡改结果或注入异常值。
- 配置发布需要权限控制、审计日志和回滚；结果文案不直接渲染未净化 HTML。
- 限制批量请求与分享图滥用；不因防刷策略误伤正常连续测试。
- 日志不得记录完整原始答案与可识别个人信息的组合。

## 附录 C：事件与数据字段

### C.1 核心数据实体

| **实体**           | **关键字段**                                                                     | **说明**                               |
|--------------------|----------------------------------------------------------------------------------|----------------------------------------|
| assessment_version | id, status, published_at, scoring_version                                        | 定义一次可复现的题库与评分版本。       |
| question           | id, version, type, text, options, dimension, direction, weights, allow_na        | 题目配置；任何发布后修改都生成新版本。 |
| session            | id, version, source, started_at, last_active_at, status                          | 匿名测评会话；不含直接身份信息。       |
| response           | session_id, question_id, value, is_na, duration_ms, revision                     | 逐题回答；支持修改历史或最终态。       |
| result             | id, session_id, type_code, dimension_scores, badge_scores, confidence, stability | 固化结果；保留算法版本。               |
| result_content     | type_code, locale, content_version, fields...                                    | 人格内容与分享文案。                   |
| share_token        | token, result_id, format, created_at, source_share_id                            | 公开分享访问与归因。                   |
| feedback           | result_id, rating, reason, text, created_at                                      | 结果认同与纠错。                       |

### C.2 建议 API 边界

| **方法** | **路径**                    | **用途**                                                     |
|----------|-----------------------------|--------------------------------------------------------------|
| GET      | /v1/assessment/current      | 获取当前发布版本、落地页与题目配置（不返回评分密钥型细节）。 |
| POST     | /v1/sessions                | 创建匿名会话。                                               |
| PUT      | /v1/sessions/{id}/responses | 批量或增量保存答案，支持幂等。                               |
| POST     | /v1/sessions/{id}/submit    | 校验并计算结果；返回决胜题或最终结果。                       |
| GET      | /v1/results/{token}         | 获取公开结果内容，不返回逐题答案。                           |
| POST     | /v1/results/{id}/share-card | 生成指定尺寸分享卡。                                         |
| POST     | /v1/results/{id}/feedback   | 提交结果认同与原因。                                         |
