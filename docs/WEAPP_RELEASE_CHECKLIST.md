# 微信小程序发布检查单

仓库只提交 `touristappid` 和公开构建配置，不负责代替微信公众平台主体、资质、隐私与版本审核。

## 构建前

- [ ] `npm ci`、`npm run build:weapp`、`npm run test:weapp-build`、`npm audit --audit-level=high` 通过；
- [ ] 真实 AppID 只在被忽略的本地私有配置或 CI Secret 中；
- [ ] 没有真实广告位 ID、域名、IP、密钥、用户数据或后台截图；
- [ ] 广告总开关仍为 `false`；
- [ ] 题库与计分版本仍为 `tt16-q20-1.0.0` / `tt16-score20-1.0.0`。

## 微信开发者工具人工验证

- [ ] 首次进入、20 题完整作答、本地结果与重新测试；
- [ ] 作答中关闭/重开后恢复，完成后关闭/重开仍能读取本地报告；
- [ ] 清除本地数据后，结果页不会从 URL 或网络恢复私人结果；
- [ ] 16 型图鉴、详情分包、四维内容与全部插画加载正常；
- [ ] 两种类型对照不含匹配分、最佳搭档或能力排名；
- [ ] 复盘勾选不收集自由文本，刷新后清空；
- [ ] Canvas 海报文字、裁切、免责声明和低多边形插画正确；
- [ ] 微信分享路径只指向公开首页/类型页，不包含答案、比例或用户标识；
- [ ] 网络面板没有答题、评分、报告、广告或第三方统计请求；
- [ ] 删除数据入口和隐私说明与实际行为一致。

## 发布前

- [ ] 检查主包小于 2 MiB，16 张插画位于 `content` 分包；
- [ ] 真机检查常见 Android/iOS 尺寸、字体、触摸区域和深色系统设置；
- [ ] 审核版本说明不使用“科学诊断”“收益提升”“适合某证券”等表述；
- [ ] 平台隐私声明明确本地存储、无账户、无券商数据和无付费；
- [ ] 广告保持关闭。流量主资格与真实广告配置必须另行评审后再发布。
